# 节点编排工作台验收记录

日期：2026-09-18。实现位于现有 `dashboard`，采用 Angular Material 3 / CDK；未提交、推送或部署。

## 需求对应证据

| 需求 | 实现与验证 |
| --- | --- |
| 三栏持续保留 | `PlanBoard` 固定输入预览、三个编排 Tab、结果预览；桌面使用可收缩三栏，面板内独立纵向滚动；850px 以下纵向排列，不产生横向滚动。真实浏览器切换三个 Tab。 |
| 多源与后端解析 | SourceManager 抽屉调用 load-source；浏览器加载两个内嵌 Surge 来源及本地 HTTP 远程来源。添加追加节点；远程刷新由 1 个节点替换为 2 个，总输入为 5 个。 |
| 编排前节点身份 | 后端 inspect_source_nodes 复用 evaluator 的外部节点准备；evaluator 测试验证 identity、原始标签、provider / policy-path 语义及失败时保留直接节点。 |
| 嵌套浏览分组 | NodeBrowser / groupInputNodes 按有序维度递归分桶。浏览器验证来源→协议层级；单测覆盖维度换序、原始标签分桶、三级展开及刷新后清除旧选择。视图状态不写 Plan。 |
| UI 构造 Plan | 自动组策略、节点组、节点标签三个 Tab；无 JSON / DSL 编辑入口。递归 PredicateEditor 覆盖 All / Any / Not / Atom 和模型中的匹配类型；MemberEditor 映射所有现有成员选择器。 |
| 自动组策略 | 浏览器建立地区→来源的组树，创建 BaseGroups Roots 包装组后，预览由“仅生成”变为“可达输出”。支持维度顺序、标签维度、手动选择及自动测速参数。 |
| 节点组 | 具名容器、策略、选择器增删排序、输出根组及空组行为；多选创建自动打开新组。父组件与操作单测验证 Plan 映射和状态不变性。 |
| 节点标签 | 按 Source.annotations 派生标签容器，可增加多个来源条件；多标签 annotation 编辑/删除只影响目标标签。浏览器名称精确匹配“香港 A”后，右侧新增标签、左侧原始属性不变。后端测试验证不级联。 |
| 受限批量拖入 | UI 禁用不合规组；写入再次检查全部 selector 为 source-bound Nodes→Atom→Name→Equals；来源+名称去重，不移除输入。浏览器验证单节点和两节点拖入；自动组引用容器拒绝；单测覆盖 OneOf、复合谓词、内置动作、旧快照和释放于容器外。 |
| 实时结果与定位 | 展示真实资源、成员图、标签、诊断、trace 和只读渲染内容；区分生成/输出资源，图遍历防循环。浏览器验证诊断跳到标签编辑、预览命中展开输入祖先；父组件覆盖 custom selector trace、过期结果禁止定位。 |
| 请求一致性与错误 | 服务按来源请求代次、输入签名和 Plan 修订隔离响应；防抖、刷新、编辑、删除、切换客户端及销毁均有测试。浏览器制造远程 404：保留旧输入，结果明确过期；恢复来源后重试成功。 |
| 订阅闭环 | 浏览器成功生成 Plan URL，并通过恢复入口重新加载输入；API 集成测试覆盖 load→evaluate→build→decode→实际订阅请求。原有本地注入入口保留，未操作用户配置文件。 |

## 使用边界

- 窄屏（850px 以下）纵向排列输入、编排和结果区域；来源抽屉最大 680px，小屏占满可用宽度。
- 成员图单次最多显示 500 行并明确提示；完整输出仍可在只读渲染结果中查看。
- 名称选择是来源+名称匹配，同一来源的同名节点一起命中。
- 本轮浏览器使用合成测试配置和回环地址 HTTP fixture；没有读取或发送真实订阅凭据。
- 主代理负责契约、集成修正、代码审查和验收；实现子代理使用 `gpt-5.6-sol / low`。

## 横向溢出修正（2026-09-18）

- 移除工作区 1120px 最小宽度，抽屉由父容器明确约束宽度。
- 选择器、源表单、预览节点卡片和面板标题随容器换行；配置预览保留换行并折行长文本。
- 真实浏览器检查 390px、961px、1105px 宽度：页面 scrollWidth 等于视口宽度，可滚动容器无横向溢出。1105px 下抽屉范围为 x=425..1105，完整显示 680px。
